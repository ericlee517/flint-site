## 涡轮火石官方网站

基于Hexo + TailwindCSS + DaisyUI搭建的静态站点，主题暂未开发社区版。

## 如何部署
请安装hexo cli后直接运行`hexo server`命令即可。

## 如何贡献
请fork本仓库，然后提交PR。

## 使用的开源项目

- [Hexo](https://hexo.io/)
- [tailwindcss](https://tailwindcss.com)
- [daisyui](https://daisyui.com)
- [Google Icons](https://fonts.google.com/icons)
